# 존재하지 않는 나를 삭제하는 법

> 나를 이루는 요소를 하나씩 지울 수 있다면, 마지막에 남는 것은 무엇일까?

나를 이루는 추상적인 조각들을 직접 지워 보는 인터랙티브 웹 아트입니다. 조각 하나를 지우면 그와 연결된 조각의 밝기, 크기, 문장이 바뀝니다. 마지막에는 무엇이 남았는지, 지운 것이 정말 사라졌는지를 돌아봅니다.

**전시 주소:** https://plaf-2.github.io/sujin-me-assignment/

이 작업은 성격 테스트나 심리 진단이 아닙니다. 화면에 나오는 문장은 모두 체험을 위한 은유이고, 사용자가 어떤 사람인지 판정하지 않습니다.

---

## 체험 흐름

| 단계 | 화면 | 내용 |
|---|---|---|
| 1 | 인트로 | 제목과 한 문장: "당신을 이루는 것 중 일부를 삭제할 수 있습니다. 단, 삭제한 것이 정말 사라지는지는 알 수 없습니다." |
| 2 | 자아 조각 | 8개의 조각이 불규칙하게 흩어져 있고, 조각 사이에 연결선이 있습니다. 조각을 고르면 상세 설명과 연결 관계가 열립니다. |
| 3 | 삭제 | 확인 단계를 거쳐 지웁니다. 제목이 글자 단위로 흩어지며 사라지고, 그 자리에는 점선 윤곽만 남습니다. 되돌릴 수 없습니다. |
| 4 | 연쇄 변화 | 지운 조각에서 연결선을 따라 빛이 이웃 조각으로 건너가고, 이웃 조각이 흐려지거나 커지거나 문장이 바뀝니다. 연결선은 끊기거나 점선이 되거나 흔적으로 남습니다. |
| 5 | 결말 | 6개를 지우거나 '여기서 멈추기'를 누르면 결말로 넘어갑니다. |

### 결말에서 일어나는 일

1. **기록 재생**: 축소된 지도 위에서 지운 순서와 시각대로 삭제가 다시 일어납니다.
2. **빈자리의 모양**: 지운 자리들을 지운 순서대로 잇는 선이 그려집니다. 같은 모양은 같은 순서에서만 생깁니다.
3. **남은 것에 대한 문장**: 남은 조각에 따라 달라집니다. 예: "마지막에 남은 것은 「혼자 있고 싶은 마음」과 「실패를 피하는 습관」입니다."
4. **처음의 나 / 지금의 나**: 처음 문장 8개와 지금의 문장을 나란히 놓습니다. 지운 문장은 원래 길이만큼의 빈칸으로 남고, 바뀐 문장에는 그 문장을 바꾼 조각의 번호가 붙습니다.
5. **단 한 번의 되돌리기**: 지운 조각 하나를 되돌릴 수 있습니다. 다만 처음과 같은 문장으로는 돌아오지 않습니다.
6. **기록 카드**: 빈자리의 모양, 지금의 나, 마지막 문장을 담은 이미지(1080×1350 PNG)를 저장할 수 있습니다.

확인 단계에서 '그대로 두기'를 누른 일도 **망설임**으로 기록되어 결말에 반영됩니다.

## 실행 방법

필요한 것: **Node.js 20.19 이상 또는 22.12 이상**

```bash
npm install
npm run dev        # 개발 서버 → http://localhost:5173/sujin-me-assignment/
npm run build      # 타입 검사 후 dist/ 에 빌드
npm run preview    # 빌드 결과 미리보기 → http://localhost:4173/sujin-me-assignment/
```

모든 주소 뒤에 `/sujin-me-assignment/`가 붙습니다. GitHub Pages가 저장소 이름을 경로로 쓰기 때문에, [vite.config.ts](vite.config.ts)의 `base`를 같은 값으로 맞춰 두었습니다.

## 배포

`main` 브랜치에 푸시하면 [GitHub Actions](.github/workflows/deploy.yml)가 빌드해서 GitHub Pages에 올립니다.

처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다. 저장소 이름을 바꾸면 `vite.config.ts`의 `base`도 함께 바꿔야 합니다.

## 내용 수정하기

문장과 규칙은 모두 `src/data/`에 데이터로 분리되어 있습니다. 화면 코드를 건드리지 않고 이 파일들만 고쳐도 작품의 내용이 바뀝니다.

| 파일 | 내용 |
|---|---|
| [config.ts](src/data/config.ts) | 몇 개를 지우면 결말로 넘어갈지 (`MAX_DELETIONS`, 기본 6) |
| [fragments.ts](src/data/fragments.ts) | 조각 8개의 제목, 짧은 설명, 상세 설명, 화면 배치(위치·크기·기울기) |
| [relations.ts](src/data/relations.ts) | 조각 사이의 연결과, 한쪽을 지웠을 때 다른 쪽에 일어나는 변화 |
| [endings.ts](src/data/endings.ts) | 결말 문장, 망설임 문장, "처음의 나 / 지금의 나" 해설, 되돌리기 문장 |
| [returns.ts](src/data/returns.ts) | 되돌린 조각이 돌아올 때의 새 문장 (조각마다 하나) |

### 연결 관계 예시

같은 연결이라도 **어느 쪽을 지우느냐에 따라** 결과가 다르게 적혀 있습니다.

```ts
{
  id: 'gaze-solitude',
  between: ['gaze', 'solitude'],
  label: '닫힌 문의 이유',
  onDelete: {
    // '타인의 시선'을 지우면 → '혼자 있고 싶은 마음'이 커지고 문장이 바뀌며, 선이 끊어짐
    gaze: {
      effects: [{ kind: 'swell', amount: 0.12 }, { kind: 'rewrite', summary: '숨기 위해서가 아니라, 그냥 닫힌 문.' }],
      line: 'sever',
    },
    // '혼자 있고 싶은 마음'을 지우면 → '타인의 시선'이 커지고, 선은 점선으로 남음
    solitude: {
      effects: [{ kind: 'swell', amount: 0.1 }, { kind: 'rewrite', summary: '숨을 곳이 없어 더 밝아진 조명.' }],
      line: 'fray',
    },
  },
}
```

- **변화(`effects`)**: `dim`(흐려짐), `swell`(커짐), `rewrite`(문장이 바뀜), `tremble`(흔들림). 여러 개를 함께 쓸 수 있습니다.
- **연결선(`line`)**: `sever`(끊어짐), `fray`(점선으로 남음), `persist`(흔적선으로 남음)
- 변화가 쌓여도 밝기는 0.5 아래로, 크기는 1.3배 위로 가지 않습니다.
- 없는 조각을 가리키는 연결처럼 잘못 적힌 데이터는 무시되고, 개발 모드에서 콘솔에 경고가 나옵니다.

결말 문장 안의 `{a}{과}`, `{t}{을}` 같은 자리에는 조각 제목이 「」에 담겨 들어가고, 뒤의 조사(과/와, 을/를, 은/는)는 제목의 받침에 맞게 자동으로 바뀝니다.

## 구조

```
src/
├─ data/          문장과 규칙 (위 표 참고)
├─ state/
│  ├─ reducer.ts        화면 단계, 선택, 삭제 기록, 망설임
│  ├─ derive.ts         삭제 기록 → 지금 각 조각과 연결선의 모습 (매번 다시 계산)
│  ├─ composeEnding.ts  결말 문장 고르기
│  └─ record.ts         기록 번호, 가능한 순서의 수
├─ components/
│  ├─ Intro.tsx                  인트로
│  ├─ Field.tsx                  조각 화면 (배치, 키보드 이동, 삭제 흐름)
│  ├─ FragmentNode.tsx           조각 하나와 그 흔적
│  ├─ RelationLines.tsx          연결선과 연쇄 변화의 빛
│  ├─ DetailPanel.tsx            상세 설명과 연결 관계
│  ├─ ConfirmDelete.tsx          삭제 확인 대화상자
│  ├─ DeletionLog.tsx            삭제 기록
│  ├─ Ending.tsx                 결말 (재생 → 문장 → 처음/지금 → 되돌리기 → 카드)
│  ├─ TraceMap.tsx               축소 지도와 빈자리의 모양
│  ├─ EndingPortrait.tsx         처음의 나 / 지금의 나
│  ├─ EndingReturn.tsx           단 한 번의 되돌리기
│  ├─ RecordCard.tsx             기록 카드 미리보기와 저장
│  └─ ErrorBoundary.tsx          오류 화면
├─ card/drawRecordCard.ts   기록 카드를 Canvas에 그리는 코드
├─ hooks/useNodePositions.ts 조각의 실제 위치 측정 (연결선용)
└─ styles/                  화면별 CSS와 색·글꼴 토큰
```

화면의 모습은 저장하지 않고, 삭제 기록에서 매번 다시 계산합니다. 그래서 연결 규칙을 바꾸면 결말의 재생과 기록 카드까지 같은 규칙을 따릅니다.

## 기술 스택

React 19 · TypeScript · Vite · CSS · Framer Motion · Lucide React
글꼴: Noto Serif KR(제목·본문 문장), Pretendard(본문). 둘 다 패키지로 포함해 외부 글꼴 서버에 요청하지 않습니다.

## 접근성

- 모든 조작을 키보드로 할 수 있습니다. 방향키·Home·End로 조각 사이를 이동하고, Enter로 고르고, Esc로 닫습니다.
- 삭제 확인 대화상자는 포커스를 안에 가두고, 기본 포커스를 '그대로 두기'에 둡니다.
- 삭제나 연쇄 변화가 일어나면 스크린리더로 알려 줍니다.
- 읽어야 하는 글자는 배경 대비 4.5:1 이상입니다. 지운 조각의 흔적처럼 일부러 희미하게 둔 장식만 예외입니다.
- 운영체제의 '동작 줄이기' 설정을 따릅니다. 움직임과 재생을 생략하고 결과만 보여줍니다.
- 데스크톱, 태블릿, 휴대폰(가로 모드 포함)에서 조각이 겹치지 않도록 배치가 바뀝니다.

## 개인정보

입력하거나 선택한 내용은 **어디에도 전송되거나 저장되지 않습니다.** 서버도, 분석 도구도, 외부 AI API도 쓰지 않습니다. 새로고침하면 처음으로 돌아가고, 기록 카드 이미지도 브라우저 안에서 만들어집니다.
